# M5 创作者验证任务包（待用户冻结）

版本：2026-10-04 草案。每项产品任务开始时，研究员只展示该产品获分配的一个任务包；第二项开始前不展示另一包，也不解释按钮位置。产品顺序与 A/B 分配按协议四组表预先确定。两包使用相同数量的新增场景、互动、换片和验收路径。

## 共用起始材料

- 使用“雨夜来电”副本和五张随附 SVG；不得修改源文件。
- 起始故事含“接听电话 / 挂断电话”两个选项和两个结局。
- 最终作品的任一完整路径应约 3–5 分钟。可通过调整场景/片段时长达到，不要求补充新的外部内容。
- 最终作品必须保留两个可到达结局，并包含一个连续点击 QTE 的成功和失败出口。

## 任务包 A：后门门禁

你正在把“雨夜来电”改成一个可分享的互动短片。请完成以下成品要求，操作顺序由你决定：

1. 保留开场的“接听电话 / 挂断电话”选择；两个选项必须进入不同路径。
2. 在“接听电话”路径加入新场景“后门门禁”。这个场景包含连续点击 QTE：显示后 10 秒内累计点击 5 次成功，否则失败；成功进入“逃离”，失败进入“循环”。
3. “挂断电话”路径继续进入“循环”。
4. 调整场景和画面时长，使从开场到任一结局的完整路径约 3–5 分钟，并且互动只在预期时间出现。
5. 在完成连线和互动后，把“后门门禁”的主画面替换为提供的另一张素材；保留已有故事与互动，处理产品提示的受影响内容。
6. 试玩以下三条结果：接听并成功、接听并失败、挂断。修复你实际看到的阻塞或错误。
7. 在 Infinite Interaction 中发布并用无登录窗口打开作品；在 OpenFMV 中保存并打开其可用的试玩或导出结果。

## 任务包 B：停电控制箱

你正在把“雨夜来电”改成一个可分享的互动短片。请完成以下成品要求，操作顺序由你决定：

1. 将开场选择改为“去后门 / 留在柜台”；两个选项必须进入不同路径。
2. 在“留在柜台”路径加入新场景“停电控制箱”。这个场景包含连续点击 QTE：显示后 10 秒内累计点击 5 次成功，否则失败；成功进入“逃离”，失败进入“循环”。
3. “去后门”路径直接进入“逃离”。
4. 调整场景和画面时长，使从开场到任一结局的完整路径约 3–5 分钟，并且互动只在预期时间出现。
5. 在完成连线和互动后，把“停电控制箱”的主画面替换为提供的另一张素材；保留已有故事与互动，处理产品提示的受影响内容。
6. 试玩以下三条结果：留在柜台并成功、留在柜台并失败、去后门。修复你实际看到的阻塞或错误。
7. 在 Infinite Interaction 中发布并用无登录窗口打开作品；在 OpenFMV 中保存并打开其可用的试玩或导出结果。

## 研究员验收表

研究员在硬停止后按产物核对，不替参与者补做：

| 项目 | 通过条件 |
| --- | --- |
| 故事结构 | 开场两个选择分别进入指定路径，两个结局均可达 |
| QTE | 10 秒窗口、5 次点击；成功和超时各只触发一个出口 |
| 时长 | 任一完整路径约 180–300 秒；记录实际值，不替参与者调整 |
| 换片返工 | 新场景主画面已替换，互动和出口仍存在；待核提示已处理或被明确记录 |
| 试玩 | 指定三条结果逐条实际运行；观察到的错误已记录 |
| 交付 | Infinite Interaction 有固定发布版本与无登录链接；OpenFMV 有其实际支持的保存/试玩或导出产物 |

若产品无法完成某项，按实际失败位置记录，不能改变任务要求或把研究员代操作记为通过。
