# 内置模型消耗预估与个人模型免计价（E01–E04）

2026-10-03 独立增量。本规格覆盖此前将全部生成任务绑定项目额度、价格配置及预留上限的描述；M2 历史签收不变。

## 产品规则

- `MODEL_CONFIGURATION_ENABLED=false`：新内置任务为 `estimate_only`；adapter 计算产品人民币预估，不查询供应商余额或账单。
- `true`：新个人任务为 `none`；不计算或展示费用、Token、余额，不因缺少价格拒绝使用模型。
- 两类新任务均不检查、冻结或扣减旧项目额度；预算配置不变，生成开关、紧急停用、并发和所有权检查保留。
- 本轮没有余额、充值、退款或自动结算功能。不能把预估当作实际扣费，也不能将个人模型显示为 ¥0。

## Adapter 与精度

活动版本为 GPT Image 2 v3、MiniMax-H3 v2。保留所有旧 adapter 版本。

`prepare(input, frozenMedia)` 返回供应商请求描述、计价上下文和实际使用的素材。Data URL 用结构化素材引用占位；`submit` 使用同一准备函数并在 Worker 内填充内容。`estimate(prepared)` 返回 CNY、整数微元、费用明细、规则版本、计算依据和 30 分钟有效期。上游展示最多六位小数，去掉尾零；不向上取整到分。

- GPT：文生图／参考图生图均按所选 1K/2K/4K 收取预估 ¥0.028/0.12/0.21。比例生成实际 size，计价依据同时记录分辨率与 size；按用户确认，不按像素面积重新分档。质量、格式不加价。
- H3：768P 每秒 ¥0.25，2K 每秒 ¥0.40；单价乘输出时长加输入视频时长，再加图片超过 5 张的部分每张 ¥0.10。音频免费，时长按核验后的毫秒累加，仅统计当前请求携带素材。
- 不读取 Base64 或联网估价；不将模型费率放到公共基础设施中。公共部分只处理准备类型、素材替换、精度检查和显示。

## 接口与历史

保留生成输入 schemaVersion 3 和现有 API 地址。目录模型增加 `consumptionMode`，不再要求 `remainingCents`。`generation-estimate` 接受空提示词用于选参数时展示预估；发送／确认仍执行完整提示词和素材校验。个人模型返回 `mode:none,status:not_applicable`，前端不请求估价。

请求卡 estimate JSON 保存费用模式；旧数据缺少模式时解释为 `legacy`。新任务 reserved_cents 保留数据库兼容值 0，不作为金额展示；不创建账户和资金流水。任务列表返回冻结 estimate，页面按模式展示。历史已确认任务仍按原快照执行和结算，新任务不进入结算待办，旧记账命令明确拒绝对新任务扣费。

浏览器确认入口拒绝旧未确认卡，要求修改保存后按当前模型来源确认；历史确认重放仍返回原任务。个人新任务不受估价有效期限制；内置确认校验报价期限、金额、规则版本以及所属项目、作者输入、模型和素材的冻结状态。按 2026-10-03 本期范围修订，新生成不绑定或校验场景/片段目标。来源切换不得静默替换模型。

结果只进入项目素材库，作者手动采用时才选择同项目目标并执行目标身份、revision/相关内容指纹、冲突和幂等校验。历史 `scope` / `contextSnapshot` 保留，已确认任务仍按原快照恢复，不据此给新请求带入编辑目标；上述范围收缩不改变本规格的费用模式或历史结算规则。

无需数据库迁移，不批量改写旧数据。内置新版本按既有机制首次使用时追加版本记录。

## 页面与验收

内置模型选参数即预估（不要求先输入提示词）；展示总额与明细、“仅作消耗预估，本版本不扣减余额”。预估失败保留当前页面输入并提供重试；个人模型不显示待估价或费用入口。两者均保持请求卡二次确认。

机器检查包括全部比例／分辨率、H3 时长与图片阈值、零额度确认及取消、重复确认、失败／恢复、历史执行和账务、个人配置无价格以及费用展示。浏览器需分别验证两种部署模式、1440/768/390px、键盘和实际 200% 缩放；受阻不记通过。只使用隔离数据及模拟供应商。
