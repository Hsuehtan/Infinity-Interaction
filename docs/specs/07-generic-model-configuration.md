# 07 · 通用供应商与模型配置

日期：2026-09-30。依据用户明确批准的通用配置重构计划。独立于已签收 M2；S1 其余工坊、结果衔接与播放撤销问题仍待处理。

## 配置结构

- `providers` / `provider_versions` 保存连接名称、HTTPS Base URL、Bearer 或指定认证头、加密凭据引用、非敏感附加头、允许结果 origin、启用状态。变更 origin 时须重配或清除凭据，不能隐式转发旧 Key。
- 模型身份沿用 `model_connections.id`。`managed_model_versions` 与原模型版本一一关联，包含供应商、输出类型、模式、参数、素材限制、协议及价格。图片/视频分别一个默认模型。旧历史配置不重写。
- 新配置采用 `generic-json`；两个内置兔子预设只是创建起点。原已配置兔子图片和视频合并到共享凭据的供应商；不同凭据引用不合并。未支持的旧协议保留原记录，不能默认为通用协议。
- 配置操作带 `commandId`、`baseVersion`，同标识不同内容拒绝；任何保存或预览均不请求供应商。

## 协议 v1 与平台限制

请求格式为 JSON，提交方法 POST/PUT/PATCH，查询为 GET。路径相对 Base URL 拼接，保留基础路径前缀；禁止指定另一个 origin、路径穿越、查询参数及 fragment。查询路径使用 `{taskId}`，值编码后拼接。

`submit.body` 是数据 AST：`$ref` 引用 `model`、`prompt`、`mode`、`params.<key>` 或素材循环中的 `item.role/type/dataUrl`；可选 `map` 做枚举映射，`scale` 做明确数字单位换算。`$media` 构造有序素材数组，`$concat` 合并数组，`$when` 按字段等值选择分支。禁止脚本、任意表达式和原型属性。必填参数及素材角色必须有映射，枚举映射需覆盖声明选项；模板深度、节点数与展开字节数均设上限。

`protocol.execution` 为 `sync` 或 `async`，与输出类型独立。异步需定义任务 ID、查询路径、状态映射；可配置查询响应任务 ID 校验。结果格式为单个 HTTPS URL、图片纯 Base64 或单图 Markdown 链接。返回错误仅记录受控代码，不透传供应商正文。

- 参数：文本、布尔、整数、小数、枚举；默认值、范围、模式条件、可见条件、条件固定值、按条件必填与互斥组合。
- 素材：图片 JPEG/PNG/WebP、视频 H.264 MP4、音频 MP3/WAV；角色限制数量、大小、尺寸、画幅、帧率及各类时长。最多 12 个，原始总量最多 45,000,000 字节，且不能突破平台上传/解码上限。缺失帧率仅对选中视频补充并缓存。
- 私有素材在 Worker 中顺序读取，校验大小及 SHA-256 后临时编码；Base64 不写数据库。序列化请求小于 64,000,000 字节。图片 Base64 先解码核验再写私有存储。
- 出站沿用公开 DNS 检查、固定 IP 的 TLS 连接、请求/响应大小和时间限制。认证请求禁止跨 origin 重定向；生成提交不跟随重定向。下载仅允许模型冻结的结果来源。
- 不支持签名认证、多阶段上传、Multipart、脚本、流式、Webhook、批量、供应商取消；已提交任务不能承诺停止。

## API 与执行

管理员：`/api/admin/providers`、`/api/admin/models`、`/api/admin/model-presets`（GET 列表，POST 脱敏预览）、`/api/admin/generation-runtime`、`/api/admin/generation-reviews`。

创作者：`GET /api/projects/:id/models?outputKind=image|video` 返回模型身份、名称、能力、参数、版本、可用原因及项目余额；不返回协议、地址、请求头或凭据。估价、消息/卡片、确认沿用已有项目接口。

新版输入为 schemaVersion 3：`modelId/outputKind/mode/prompt/parameters/media/referenceSelections`；提交卡片时附命令身份、请求版本及所属项目。按 2026-10-03 本期范围修订，新生成不绑定场景/片段目标。未传参数使用声明的默认值；显式非法值不自动替换。旧 schema 1/2 与单首帧请求继续使用旧解释，升级编辑时新卡片重新确认；不修改旧任务快照。

发送原子保存消息与请求卡，冻结所属项目、作者输入、模型/供应商/凭据版本、协议、有效参数、素材摘要、显式设定引用及适用价格信息。执行快照独立存放，不能出现在创作者响应。确认重新核对项目权限、版本、适用报价和素材；不一致则更新卡片，不校验未绑定的场景/片段目标。并发确认只产生一个任务。普通工坊未发送输入和设定表单均不持久化；发送重试以请求标识幂等。

生成结果只进入项目素材库；作者手动采用时才选择同项目目标，采用命令仍需校验目标 ID、revision/相关内容指纹、冲突和幂等。历史 `scope` / `contextSnapshot` 不删除，既有任务继续按原快照恢复；历史编辑目标不驱动新工坊界面或注入新请求。本次不改变协议、模型或费用规则。

价格用声明式档位：按次、输出秒、输入视频秒、超额图片；价格单位厘（千分之一元），计算精度微元，最终预留金额向上取整到分。费用明细与精确估计分开，旧费用快照保持原样；不将预留或估价标为实扣。图片/视频共用每项目预算与并发限制。

Worker 每 10 秒心跳，30 秒过期；运行开关关闭时不提交，部署紧急停用优先。提交前失败可释放额度；已发出请求但响应不确定进入 `submit_unknown`，不自动重发。管理员按供应商证据恢复查询或入库。查询、下载、入库可重试，私有写入幂等。任务 ID 以 `(provider_namespace, provider_task_id)` 唯一，默认命名空间为供应商 origin，跨模型/账号同 origin 的重复任务不能重复关联。

## 页面与验收边界

管理页按“选择供应商 → 管理模型”组织，总览展示连接、模型能力与可用原因。按 2026-09-30 用户后续反馈，供应商表单仅保留名称、空白 Base URL、API Key 三项；新建必须填写密钥，编辑留空保留，加密保存。保存使用 Bearer、无附加头、供应商启用，不再显示认证方式、密钥动作、启用或高级连接设置。旧协议与冻结凭据保留兼容执行，不批量改写历史。

模型表单分为基本信息、可用输入与参数、接口映射。基本信息显式选择图片/视频、同步/异步；现有模型的输出类型保持不可变。示例是可选填表起点，按模型类型筛选；手动新增模型不自动套用兔子协议。模型的启用与默认选项保留。

2026-10-01 R 增量替代此前的参数与映射表单规则：生成参数仅保留名称、标识、枚举 JSON 与默认值；配置成带默认值的必填单选，移除类型/范围/请求路径/必填开关。第二步不隐式创建请求字段。数字、字符串和布尔枚举保留原类型。删除参数列出协议、模式、其他参数及价格引用，先解除引用再删除。v2 保存拒绝自由输入参数；v1 历史继续按原契约执行。有限整数范围等价转枚举（包括 0–100 的 101 个值）；不猜测旧自由文本选项。

第三步按①提交请求、②提交回执任务 ID、③轮询请求、④轮询状态与错误、⑤生成结果组织，同步只显示①⑤。2026-10-01 J 增量以直接 JSON 请求模板替代 R 的“应用结构→逐字段绑定”：提交体、轮询查询参数与 POST 轮询体各有一个编辑入口，统一保存模型。嵌套对象、数组、根级条件、素材循环仍完整显示在模板中；不再显示树形绑定编辑器。接口路径保留供应商前缀，不允许替换 origin。

v2 协议给 query 增加 method（GET/POST）、params、body；GET 不含 body，POST 可携带 JSON。taskId 必须映射到路径、参数或 body，不再必须位于路径。任务 ID 接受字符串或安全整数，generation_jobs.provider_task_key 追加保存原 JSON 类型，provider_task_id 继续存规范化文本及命名空间唯一性。提交与轮询有独立 error 规则（非空/不等于成功值，及消息路径），保留 v1 errorPath 解释。未知状态、解析缺失显示脱敏原因，不重复付费提交。

预览端点仍为 /api/admin/model-presets POST，兼容原 method/url/headers/body，同时返回 submit、可选 query 和示例响应解析；请求支持可选 taskId 与 samples。页面可选择模式、参数、任务 ID 和提示词，Worker 与离线预览使用同一组装/取值函数。返回字段仍支持 URL、图片 Base64、单图 Markdown。价格不进入表单或完整能力编辑。

结果文件域名属于模型结果配置 `protocol.result.origins`，不再增加供应商必填项。未填写沿用旧供应商允许来源，新供应商默认 Base URL origin。独立 CDN 需显式填写公开 HTTPS origin；保存校验和既有 DNS/大小限制继续有效。任务冻结时合并到执行快照的结果来源，旧任务来源不变，下载不携带供应商密钥。统一可用原因区分未启用、配置错误、缺凭据、计价待维护、运行关闭、服务离线；保存不代表供应商验证成功。

2026-09-30 用户调整边界：模型 API 页面不提供价格配置，价格表单及高级 JSON 的 `pricing` 字段移除。编辑已有模型时保留价格策略，选择示例也不能覆盖已有价格；新模型选择已有示例时暂沿用该示例规则，纯手动模型标记 `pricing.configured=false`，可保存和预览，但不得按虚构的零价格创建任务。独立定价代码模块后续开发，本轮不迁移计价数据或改变历史报价/任务快照。运行开关、共享预算与历史额度处理保留在默认收起的“运行与任务管理”中；共享预算是使用限额，不是模型单价。

工坊与卡片使用同一动态输入组件；切模型保留提示词和已有输入，不兼容字段保留并明确阻止发送，提供移除入口。目录失败显示重试；素材上传沿用有超时和可恢复错误的媒体客户端。结果预览、应用与撤销沿用既有实现。

验收包含四种同步/异步图片/视频组合、替换域名/模型/字段/枚举的模拟接口、权限与脱敏、任务幂等、提交不确定不重发、入库恢复、旧接口及历史快照。实际页面的窄屏、键盘、刷新、文件上传仍需浏览器或人类实测；组件测试不能替代页面通过。真实供应商验收另行指定，本阶段零真实生成调用。

## J 增量：统一输入与直接 JSON 模板（2026-10-01）

本节为当前编辑交互，替代历史 R 的请求体绑定表单；历史 R/M2 签收状态不变。没有新增数据库迁移，也不批量改写当前模型版本。打开旧配置仅转换显示，用户保存时才追加版本；历史卡片、任务、费用与凭据快照不变。

步骤二按创作输入、自定义参数、系统数据分组。共享 `inputSources` 目录供页面及前后端引用校验使用。目录包含提示词、模式、参数、模型标识；异步才展示仅限轮询的任务 ID。素材按模型已有模式角色展示，不能因输出类型自动获得其他素材能力。`assets.first_frame/last_frame` 是单个 Data URL，其他 `assets.reference_*` 是有序数组；缺少单帧的活动分支会报错。`item.dataUrl/type/role` 仅限素材循环。目录不包含 Base URL 或凭据。

模板约定：

- 完整字符串值 `${model}`、`${prompt}`、`${mode}`、`${params.key}`、`${assets.reference_image}`、`${taskId}` 引用来源；替换保留 JSON 原类型，只解释一次。
- 固定值直接填写；固定文本中的 `${name}` 写成 `$${name}`。不允许字符串内部拼接，占位符也不能作为供应商字段名称。供应商固定字段不需要在步骤二定义。
- 条件写成 `{"$when":{"field":"${params.output_format}","equals":"png"},"then":{"$omit":true},"else":"${params.output_compression}"}`；`$omit` 只用于对象字段。
- 素材循环 `$media` 内可引用 `${item.dataUrl}` 等；`roles` 过滤已有角色，`$concat` 拼接数组。
- 转换写成 `{"$value":"${params.resolution}","map":{"1K":"1024x1024"}}` 或 `{"$value":"${params.duration}","scale":1000}`。转换表值为固定 JSON 值。
- 轮询路径显示 `${taskId}`，存储仍为 `{taskId}`，继续进行 URL 编码。GET 不发 body；POST 可配置查询参数与 JSON body。

编辑器提供格式化、中文行列定位、复制输入及三个复杂模板示例。步骤切换、非法 JSON 和版本冲突保留输入；无效文本阻止保存上一份有效结构。模式与能力高级 JSON 不再包含请求模板，避免两个入口相互覆盖。

`compileTemplate` 与 `templateFromBody` 在 JSON 编辑表示和原 AST 间转换；预览与保存共用编译结果，Worker 继续执行原 AST。旧固定文本自动转义。现有图片和视频预设往返转换及请求等价有测试。v1 历史严格规则继续保留；v2 对未使用参数返回 `warnings[{code,path,message}]`，管理员保存与预览均可成功。未知引用、阶段错误、循环外当前素材、模型不支持的角色均阻止保存并定位 JSON 路径。条件和转换里的引用计入使用。静态校验不承诺供应商接受其固定字段；活动分支缺少实际输入在预览/执行阶段单独报错。原素材归属、大小、归档保护及网络限制不变。
