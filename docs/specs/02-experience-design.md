版本：1.2 · 本期范围修订：2026-10-04 · [返回规格入口](README.md)

本文件以当前 UXdemo 为交互基线，补齐正式产品约束；不把模拟服务视为生产实现。范围以 [01](01-product-scope.md) 为准，原型差异见 [05](05-prototype-alignment.md)。

## 1. 信息架构

进入顺序：项目首页 → 选择/新建项目 → 项目内工作区。

项目内采用左侧导航、右侧工作区；Logo 与侧栏一起展开/收起。收起后入口保留图标下方短标签。当前项目入口显示项目名称；完整名称在收起时可通过可访问名称/提示查看。

左侧顺序：项目首页、当前项目卡片（项目）、故事、AI 工坊、素材、设定、试玩、发布；“模型 API”按 08 的部署开关开放给登录用户并限定个人归属，项目内位于发布下方。剪辑器是场景的局部视图，从画布进入；可保留“继续剪辑”快捷入口，但不能产生第二套场景列表或另一个制作流程。素材页是统一资产管理，工坊是唯一创作 AI 界面，两者引用同一 Asset。

所有页面取消全局顶部栏，工作区从顶端开始；不再用通栏重复展示项目名、页面名或返回路径。页面自身标题、局部标签、浮动工具和表单标题保留。取消“故事蓝图 / 场景工作台”全局重复切换，取消“整理故事 / 准备视频 / 添加玩法 / 剪辑与调整”四阶段导航。

AI 素材工坊使用“生成 / 任务与历史”两项局部导航；生成输入区内选择图片/视频输出类型，不新增第二个工坊或独立“队列”一级页面。图片增量详见 [06](06-reference-library-and-image-generation.md)。

## 2. 故事画布

### 2.1 核心操作

1. 新项目提供空画布或明确的空白起始场景，不自动填入样例剧情。
2. 作者添加、重命名、复制、删除场景，编辑原文，手工连接场景与出口。
3. 单击节点主体或预览直接进入剪辑器，聚焦节点后 Enter 进入。标题拖动、端口、菜单等操作不触发打开；完成拖动后必须抑制误点击。多选使用框选或修饰键，不要求先显示摘要再打开。
4. 进入剪辑器后返回时恢复画布位置、缩放与选中节点。
5. 新场景即使没有视频也能放在图上，不强制先确认原文或 AI 分镜。

节点沿用本地 OpenFMV 的结构与操作语义，展示标题、起点/场景/结局标识、媒体预览、时长、素材/互动数量及逐项出口。原文、类型、复制/删除在节点菜单内编辑，不增加常驻属性栏。不要显示四阶段完成率。普通场景、起始与结局沿用 OpenFMV 的语义，不因新增模板而添加“点击/QTE/收集”等故事节点类型。

支持标题拖动、网格吸附、平移、滚轮缩放、框选、删除及撤销。悬浮工具提供新增场景、素材、平移/选择、自动整理；底部提供缩放与适应画布。320px 节点、15px 吸附为原型参考值，不要求为像素复刻改写 OpenFMV 核心。

### 2.2 连接与检查

画布回答“后面去哪里”，详细互动时间和画面布局在剪辑器编辑。通过出口圆形端口拖到目标节点连线，也可点击端口选择已有目标、创建下一幕或断开；端口和菜单需有键盘替代操作。选中连线可查看它对应的选项或默认出口。修改目标需同步反映在剪辑器的结果设置中，不双向复制两份目标值。

删除被引用场景时提示受影响入口；确认后允许保留草稿中的待修复引用，不能静默改向其他场景。断开的必需出口阻止发布。非终止循环提示风险，但有明确退出方式的循环不是一律禁止。

## 3. 场景剪辑器

### 3.1 布局与入口

- 不新增顶部通栏；返回故事画布放在素材区，当前场景名和试玩按钮放在预览区。
- 素材区：项目素材、上传；如保留“生成视频”，只跳转独立工坊。
- 中间：视频预览与画面内互动对象。
- 下方：OpenFMV 节点级媒体/互动时间线。
- 属性：剪辑器内部“当前对象 · 编辑”区域，按选中媒体或互动展示对应字段；不是全局右侧页面。
- 原文：可展开的参考/编辑区，不默认占据半屏，不要求先点击“内容确认”。

用户无视频时可上传，或通过普通入口进入工坊生成后再手动选入场景；也可以先在画布规划故事。一个完整视频可以直接插入场景，不强制拆镜。多个上传/生成片段可以混合排列。

### 3.2 剪辑

复用已存在的选中、拖动、裁剪、分割、复制、删除、撤销重做及音频操作。新增数据/服务通过外层适配进入现有命令，不重新实现一份演示剪辑器作为生产版本。

视频、图片、音频进入媒体轨；按钮/QTE 进入互动轨。不要求用户理解底层 track 类型，但不得引入第二套独立玩法时间线。

切换场景保存并恢复当前片段、播放位置和面板状态。未保存更改不允许静默丢失；离开时若云保存失败，展示重试与导出恢复数据的办法。

### 3.3 手工添加互动

作者点击“添加互动”，选择 [01](01-product-scope.md) 定义的模板。

交互路径：选择模板 → 在画面上放置/调整 → 在时间线上设定窗口 → 选择已有故事出口 → 测试。

属性面板只显示所选模板需要的字段：文字/提示、时间、区域、次数、暂停方式、结果。固定区域点击直接在画面上绘制矩形；不显示“AI 分析”“接受绑定”等入口。

模板给出可编辑默认值，第一次添加即呈现可操作的示例形态，但不得替作者决定剧情目标。缺目标用清楚的“请选择结果场景”提示。

提供“测试此互动”与“试玩本场景”。试玩状态独立于作者工程，不把操作次数等玩家状态写回作品配置。

无互动无需专门点“纯观看确认”；符合默认出口规则即可播放。普通选择的多个按钮构成一个选择组；不同互动窗口若重叠，给出阻塞提示，首版不自动决定谁优先。

## 4. AI 素材工坊

### 4.1 对话式图片/视频生产

“生成”页为对话记录、当前项目及模型信息和底部输入区。空态按当前输出类型展示画面描述示例；示例仅填入当前输入，不直接提交任务。图片支持文字生图/参考图生图；视频沿用 W01–W06 的三模式及后续动态配置。当前工坊内切换类型时共享提示词，并为图片/视频分别保留模型、参数和参考素材；参数、素材和适用预估分别校验。没有实际能力时明确不可用，不把预留入口标成已支持。最新输入排布、提示和素材引用规则见本文件 CN/MR 增量。

1. 输入文字，Enter 发送，Shift+Enter 换行；中文输入法组合输入期间 Enter 只完成选字。
2. 消息展示为用户记录；系统整理为请求卡。新描述或补充参数均显示最终生效的完整描述，不隐藏对原意的修改。有歧义时追问或保留待填，不替作者构思剧情。
3. 卡片展示所属项目、输出类型、模型、描述、将外发的资料及适用参数。视频显示时长等参数，图片显示适配器支持的尺寸/画幅。参考选择器支持项目素材与“从设定选择”，选具体文件而非自动展开整份设定；简介只有显式加入描述才外发。费用按 09：内置展示消耗预估，个人模型不展示费用入口。
4. 作者可以修改描述、取消待确认请求或确认生成。**发送消息不创建图片/视频任务；确认请求卡才提交任务。** 新任务不预留或扣减旧项目额度；历史任务处理规则按 09 保留。
5. 修改请求产生新卡片并使旧待确认卡失效；已提交任务不受影响。不能确认已经取消/被替代的卡片。修改当前输入也不能改变已展示卡片的快照。
6. 确认后的卡片显示同一个任务的运行、失败、取消与结果，不在每次轮询时添加一条重复消息。完成后可预览、采用、查看输入、定位工坊历史。
7. 重试保留原有效输入并产生新的待确认卡，按当前来源和费用模式确认。清空当前输入不是取消已执行任务。

所有新任务都属于当前项目，结果只进入项目素材库，不隐式创建节点或改时间线。参数按实际能力列举，原型固定时长不是产品上限。普通聊天协议配置不自动成为图片或视频供应商。

任务流转时保留正在输入的文本、光标与滚动位置。用户正在回看历史时不自动滚到底部；发送消息或已经在底部时可跟随新状态。消息失败应可原地重试，不能显示为成功并丢失当前输入或本次提交标识。

### 4.2 任务与历史

任务可按全部、进行中、失败、已完成、已取消及图片/视频类型筛选。显示可理解的状态与错误；供应商没有进度百分比时显示处理阶段，不虚构完成百分比。

生成完成后，可预览、重命名、查看生成描述与显式引用资料。执行“插入场景”或“替换片段”时，由作者从同项目中明确选择目标和位置；采用记录可列出已使用位置。素材可多次使用，不能只允许一个绑定位置。历史任务中的来源信息可只读展示，不驱动新请求、默认目标或页面导航状态。

图片结果增加私有预览/授权下载及“存为设定”：作者选择人物/场景/道具，补齐名称、简介后明确保存，可增选其他项目图片。不因当前选中了视频片段就自动替换它；媒体插入仍走既有手动命令。保存设定失败保留表单；撤销建设定不删除结果或退款。

历史结果不是聊天附件备份。所有已入库结果都具有独立素材身份；旧候选持续保留，采用新候选不销毁旧文件。

## 5. 工坊入口与输入状态

### 5.1 唯一入口

AI 工坊是本期唯一创作 AI 界面，通过项目导航或页面内的普通跳转进入。任意入口均打开当前项目的持久会话并创建新的未发送输入；输入来自作者填写的描述和显式选择的参考资料，采用目标在结果应用时选择。公开玩家页面不提供创作者生成操作。

### 5.2 工坊自身必须保留的状态

每个项目持久保存工坊消息、请求卡、任务及唯一 requestId/jobId/assetId。未发送输入只存在于当前组件：生成/历史切换保留，离开工坊、切换项目、刷新、关闭页面或服务重启后丢弃。上述操作不得重新提交任务。

工坊输入保留键盘、中文输入法、错误恢复和历史滚动能力；任务刷新不吞字、不把正在回看的历史强制滚到底部。不同浏览器标签页无需同步未发送输入，但仍须防止重复发送、重复确认和重复采用。窄屏保证工坊基本操作可达。

旧 scope/contextSnapshot 仅作历史请求卡和任务兼容；既有任务按冻结输入恢复，不改写历史，也不把旧编辑目标注入新的生成输入。

## 6. 结果采用与返工

### 6.1 插入

选定项目素材 → 作者明确选择同项目目标场景与插入位置 → 应用。目标在本次采用操作中确定。提交前显示目标身份和实际位置；应用时校验项目所有权、目标 ID、revision/相关内容指纹与幂等，冲突时保留素材并要求重新选择，不能自动改到其他场景。

### 6.2 替换

替换前显示目标片段名称、旧/新视频和实际时长差异。默认保留片段身份、起点和故事出口；新媒体足够长时保留原时间线占用时长，从明确显示的源起点使用新视频。

新视频过短、源裁剪区间无效或需要改变占用时长时，要求作者选择调整方式；不自动拉伸、补帧或移动整段后续内容。改动影响哪些互动与后续片段，要在应用前说明。

保留互动意图、参数和出口。媒体内容变了的相关区域点击提示“请核对位置”；时间越界为硬错误。只标记受影响范围，不因一次换片把整个项目标成待审批。

### 6.3 修改原文

原文不再是强制生产计划。改原文保存即可；保留既有视频和互动。新生成不自动读取原文或绑定其版本；历史来源记录保持只读兼容，不要求逐条“再次批准视频”。

### 6.4 撤销边界

插入、替换、连接、编辑互动等项目修改可撤销。撤销采用视频不会删除生成素材、撤销供应商任务或退款。重复点击同一“应用”不得重复插入；作者主动再次使用素材仍合法。

## 7. 保存、预览与发布

显示“保存中 / 已保存 / 保存失败”以及可执行的恢复办法，不用成功提示掩盖错误。编辑过程中允许保存不完整草稿。

发布前检查：有效入口、可达场景的必需素材、互动时间与结果、片尾行为、待核对区域、资源访问性。只检查作品引用的素材；未采用的生成任务未结束或失败，不阻止已完整作品发布。

应用检查失败可直接定位对象。发布以确认的草稿 revision 创建固定快照；构建期间继续编辑不改变该快照。首次真正发布前提供分享范围确认；返回的是真实可访问的 Web 作品地址，不是本地演示链接。

## 8. 典型路径

1. 全上传：新建项目 → 手工建立故事 → 上传视频 → 剪辑并放置互动 → 连线/检查 → 试玩 → 发布；不打开 AI。
2. 混合生产：在工坊生成 → 继续手动编辑 → 工坊或素材库查看结果 → 明确选择同项目场景/片段进行插入或替换 → 试玩；生成与采用分别确认。
3. 独立生产：工坊生成视频 → 结果进入项目库 → 以后从剪辑器选用。
4. 设定生产：设定页直接进入普通工坊 → 选择文字/参考图生图 → 结果明确存为人物设定 → 视频生成时选择其中一张或多张图片 → 确认请求；未选的场景/音色文件不会自动加入。
5. 全上传设定：上传人物/场景/道具图片与音色音频 → 分别建立多文件设定 → 在生成输入中按模式显式选用；不依赖图片生成服务完成管理。

## 9. 外部模型 API 配置

### 9.1 入口与权限

页面不设全局顶部栏，项目内导航位置在“发布”下方；是否展示以及直接路由/API 是否可用由 [08](08-model-source-modes.md) 的部署开关共同控制。关闭个人配置时仅使用内置模型；开启时登录用户在首页或项目内仅管理自己的供应商、凭据和模型，工坊不回退内置目录。原型的直接展示不能作为生产权限依据。

模型配置按用户归属，不随项目导出或撤销；不同用户不能访问彼此配置。页面按供应商→模型组织，展示能力和可用原因，不能将“保存成功”显示成“供应商已验证”。不再提供旧全局运行/账务/未知提交核实的浏览器运维入口，详见 08。

### 9.2 新增/编辑字段

当前表单以 [07](07-generic-model-configuration.md) 的 R/J 增量为准，配合 08 的个人归属，不恢复原型的旧管理表单：

- 供应商只填名称、HTTPS Base URL、API Key；新建必须有 Key，编辑留空保留，不回读密钥原值。改变 origin 的凭据处理和出站限制仍按服务端契约。
- 模型按基本信息、可用输入与参数、接口映射组织；输出类型、同步/异步、模式能力、枚举参数和直接 JSON 模板按 07 校验，不从名称猜支持能力。
- 个人默认模型按用户及输出类型唯一；不显示模型价格配置。个人新任务无价格也可用，不恢复旧 pricing 必填门槛。
- 输入错误定位到字段或 JSON 行列；无效输入、步骤切换和版本冲突保留表单。保存/取消、Escape 和焦点返回保持可达。

移除配置不删除项目、素材或生成历史；不能删除恢复既有任务所需的配置/凭据版本。停用默认不自动挑选替代，保存及离线预览均不调用付费接口。

### 9.3 生效与安全说明

原型非密钥配置和内存 Key 仅作历史演示。正式配置与凭据服务端托管；启用不是认证成功，只有来源可用、凭据有效且支持对应输出/输入模式的配置才可调度。内置版本、个人 JSON 配置及历史执行均按 07/08，不能因保存聊天协议就宣称已支持生图。

更改默认或部署来源不重定向已提交任务。待确认卡按当前来源和版本规则要求重新确认；优先校验作者显式选择的兼容模型，未选择且无可用默认时阻止，不自动挑选其他服务。工坊目录不暴露协议、地址或 Key。费用呈现严格按 [09](09-model-consumption-estimates.md)：内置为消耗预估、个人不展示费用，两类新任务均不扣旧项目额度。

## 10. 项目设定与素材

“设定”提供人物、场景、音色、道具分类，名称、简介和至少一个主体文件必填，允许多文件。人物/场景/道具为图片，音色为音频；支持上传或选择已有素材、预览/试听、增删文件及设定。完整设定不能保存为零文件。设定之间的关联功能已撤销。表单只在当前弹窗保留输入，关闭、取消、跳转或刷新后丢弃；无持久草稿或恢复入口。详见 [06 §3–4](06-reference-library-and-image-generation.md)。

图片类提供“生成设定”跳转工坊；音色只上传/选音频，不生成或克隆声音。设定页与工坊都不自动新建设定。跳转与左侧导航进入普通工坊一致，不携带设定表单，不增加返回设定或切换设定图片输入的功能。

素材页统一查询视频、图片、音频及生成结果；设定引用同一 Asset，不复制文件。旧纯文字/other 资料保留为待补齐/历史分类，不因新必填规则阻断旧项目编辑。生成只外发作者选入请求卡的文件和文本，修改设定不改变已提交任务或作品。

## 11. 视觉与可访问性边界

使用 Infinite Interaction 品牌、深色工作台、侧栏收起后的文字与原有无顶部栏结构。保持清楚的焦点、选中/禁用/错误状态；按钮不能靠颜色作为唯一状态提示。表单必须有标签，文本/提示采用可验证对比度，网格同排对齐、窄屏输入和确认操作不被遮挡。

本期优先功能可用：工坊、素材、设定、编辑属性和发布的主要操作必须可见、可达，错误与状态可理解。展示审查保留历史问题证据；未变化的四尺寸/IME 等证据按 plan §7 复用，对实际受影响路径补验。不恢复顶部栏、全局右侧属性页或四阶段流程。详见 05。

### CN 补正：GPT Image 2 多参考图（MR01）

用户明确要求参考图生图支持多张。GPT 当前 adapter 升级为 v4，取消单图数量与仅发送第一张的实现，采用兔子 /v1/images/edits 的 multipart 重复 image 文件字段。数量上限沿用平台现有 12 项，原始文件合计 45 MB；这是平台资源边界，不声称供应商支持无限张。文生图和历史执行版本不变，价格继续按所选 1K/2K/4K 档位。
