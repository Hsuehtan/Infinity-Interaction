# 模型来源双模式（B01–B06，2026-10-02）

本增量覆盖此前规格中管理员/创作者模型权限、全局模型目录和浏览器运行设置条款。M2 签收和历史快照不重开；J04 的旧页面待验项独立跟踪。

## 行为

- 服务端 MODEL_CONFIGURATION_ENABLED 默认 false，修改后重启 Web/Worker。false 仅代码内置目录，隐藏模型 API 入口并阻止直接路由、新旧配置接口。
- true 时所有登录用户都可在首页或项目内访问模型 API，只管理自己名下的连接、凭据和模型。工坊只列当前用户个人模型，不回退内置模型。
- 登录、会话和项目/素材/任务所有权保留；用户角色字段已移除。默认模型按用户及输出类型唯一。
- 原全局运行、账务及不确定提交核实接口对浏览器关闭，运维通过本地命令执行。来源开关不影响生成运行开关、预算或紧急停用。

## 代码组织

实现目录：InfiniteInteraction/server/models/adapters。tuzi/gpt-image-2.ts 与 tuzi/minimax-h3.ts 独立声明稳定 UUID、能力、工坊枚举及模式、请求组装和响应解析。registry.ts 分开注册可选模型与保留的历史版本；公共执行器只负责分派，网络层负责注入凭据、地址限制、超时、大小检查与脱敏。

GPT v1 历史文生图用 v1/images/generations，参考图用 v1/chat/completions；IW 阶段 v2 两模式均使用 v1/images/generations，参考图增加 image Data URL。MiniMax 三模式使用已有 v2/video_generation 和 v2/query/video_generation。API Key 不进入代码和能力目录。B 阶段适配器引用既有价格策略；后续 E 增量的新任务规则以 [09](09-model-consumption-estimates.md) 为准。

## 数据与兼容

030_model_sources 追加个人归属、来源、部署凭据绑定和内置版本表；providers.owner_id 来自 created_by，模型跟随当前关联供应商归属。历史 ID、版本、任务和费用快照不变；不批量改写协议。

新卡片冻结来源、能力、供应商与凭据版本、适配器 ID/版本和价格。个人使用原 JSON 执行器，内置按固定代码版本执行。已确认任务不随来源切换或凭据轮换改变；未确认旧卡片必须重新选择可用来源。缺少适配器版本明确阻止，不使用最新版本替代。下架只移除活动注册，不移除历史注册。

## 运维

本地命令说明见 InfiniteInteraction/server/models/adapters/README.md。先备份并停止正常 Web/Worker，执行迁移、历史哈希核对和凭据绑定，再启动。运维审计用户名不构成浏览器权限；命令需本机数据库与密钥保管环境访问能力。

## 验收

仅隔离 DB、私有存储及注入模拟供应商，禁止本轮真实生成。覆盖双用户隔离、双来源门控、历史冻结、五种内置生成模式映射、同步/异步模拟入库、幂等及响应不确定不重发。页面证据与人工签收分开，详见 tasks/reports/model-sources-b01-b06-2026-10-02.md。


## 2026-10-03 Image 2 v2 与工坊参数修正

活动注册升级至 GPT Image 2 adapter v2，旧 v1 保留执行。新增比例枚举（Auto 与 15 个固定比例），按分辨率和比例计算具体 size；Auto 默认方图。文生图的质量与格式选项不变，参考图继续仅展示尺寸相关选项；JPEG/WebP 压缩质量固定 100，PNG 省略，不再提供压缩控件。具体 48 项尺寸表见 [IW 报告](../../tasks/reports/workshop-image2-2026-10-03.md)。

工坊加载/切换模型时移除不支持的参数，并以当前模型默认值替换不合法值；提示词、素材不自动删除，历史冻结任务不改写。缺少输入通过发送入口说明，保留安全校验；不常驻显示底部技术红字。此次规则优先于早期“保留不兼容参数并由用户手动移除”的交互约定。
