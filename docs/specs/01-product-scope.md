# 01 · 产品定位与 MVP 范围

版本：1.2 · 本期范围修订：2026-10-04 · [返回规格入口](README.md)

## 1. 产品定义

Infinite Interaction 是基于 OpenFMV 二次开发的浏览器互动视频创作工具。作者用故事画布组织剧情，在场景剪辑器中编辑视频、声音和互动，可通过上传或内置 AI 生成获得视频，再发布可分享的浏览器作品。

核心原则：**关闭 AI 也能完成作品；打开 AI 不需要进入另一套项目体系。**

AI 工坊是本期唯一创作 AI 界面，与编辑器共用项目素材、任务和手动采用规则。作者在工坊独立描述生成需求，在采用结果时选择编辑目标。第一版优先完成功能可用的编辑器与素材生产闭环。

## 2. 用户与承诺

目标用户是有内容和剧情设计能力、不会编程、愿意学习基本剪辑和少量互动配置的创作者。

- 作者负责故事原文、分支、对白、成功/失败结果以及最终审美判断。
- 工具负责可视化编辑、稳定执行互动、管理素材与设定、生成图片/视频和发布。
- 创作输入使用画面描述、参考图、时长等语言，不要求模型部署或编程知识；模型来源按 [08](08-model-source-modes.md) 分为代码内置与用户个人配置，不能把早期“不需要 Key”解释为取消已确认的个人模型能力。
- 不承诺“只给小说就自动变成游戏”；不承诺 AI 自动设计好玩的玩法或达到指定商业作品画质。
- 最终产品仍面向降低制作门槛，而不是降低剧情设计要求。复杂程度与质量上限不能仅用玩法模板数量衡量。

## 3. 首轮验证假设

H1：创作者可以在无开发者代操作的情况下，完成一个有完整开场、分支和结局的可玩作品。

H2：统一的场景编辑、素材采用和返工流程，比直接组合独立工具减少重复配置、文件搬运或返工。

H3：作者实际采用内置生成的视频，而不是只尝试生成；生成与编辑之间的衔接对作者有价值。

不得把生成次数、模板数量或“AI Native”表述当作差异化已成立的证明。测试先隔离编辑器能力，再验证视频生成，见 [04](04-delivery-and-acceptance.md)。

## 4. P0 范围

| ID | 必须交付 | 边界 |
| --- | --- | --- |
| P-01 | 项目首页、新建、打开、项目自动保存 | 单人拥有项目；草稿云端保存，不依赖 localStorage 作为真源 |
| P-02 | 故事画布 | 手工创建、编辑、连接开始/场景/结局；可先用原文和空场景规划 |
| P-03 | 场景剪辑器 | 复用 OpenFMV 媒体轨、互动轨、视频/图片/音频编辑与可用命令；不另建剪辑内核 |
| P-04 | 少量手工互动模板 | 普通选择、限时点击、连续点击，以及固定区域点击的基础呈现；共用已有按钮/QTE 规则 |
| P-05 | 项目素材库与上传 | 上传视频、图片、音频；统一元数据、预览、引用和采用 |
| P-06 | 对话式 AI 素材工坊 | 消息描述、请求确认卡、任务与历史、候选预览和手动采用 |
| P-08 | 可恢复的生成任务 | 明确提交、按费用模式展示信息、失败与安全重试、服务重启恢复；新任务不走旧项目额度，详见 09 |
| P-09 | 项目内手动采用安全 | 生成只入当前项目素材库；采用时作者明确选择目标，校验目标身份、版本、冲突与幂等，不自动改时间线 |
| P-10 | 预览、检查和 Web 发布 | 从当前场景试玩、从项目入口试玩、不可变发布快照和可分享链接 |
| P-11 | 最小安全与任务控制 | 项目级鉴权、素材权限、服务端凭据托管、来源门控、生成开关和并发限制；旧额度仅兼容历史 |
| P-12 | 项目媒体设定 | 人物/场景/道具用图片，音色用音频；名称、简介、至少一文件必填，允许多文件；设定之间不提供关系功能 |
| P-13 | 模型 API 管理页 | 按部署开关使用内置目录或登录用户个人配置；个人连接互相隔离、密钥服务端托管，详见 07/08 |
| P-14 | AI 图片生产与设定衔接 | 文字生图、参考图生图；结果明确存为设定；设定文件显式用于图片/视频请求，详见 06 |

### 4.1 玩法的确定性边界

作者直接设置出现时刻、操作区域、结果出口，并在预览中测试。不经过“让 AI 提案 → 接受绑定 → 确认方案”的程序。

| 模板 | 必需参数 | 预期行为 |
| --- | --- | --- |
| 普通选择 | 选项文字、位置、时间、目标场景、是否暂停等待 | 点击执行对应出口；无操作时按已设置的等待/默认出口处理 |
| 限时点击 | 操作提示、有效窗口、成功与超时出口 | 窗口内一次有效点击成功，未完成走超时出口 |
| 连续点击 | 操作提示、次数、有效窗口、成功与超时出口 | 次数达到阈值成功；触摸和桌面点击均可用 |
| 固定区域点击 | 画面矩形、提示、有效窗口、结果 | 属于按钮/QTE 的可视化模板；不自动识别目标，不承诺跟踪移动物体 |

底层 `button` 与 `mode/qte` 能满足时直接复用；不为 UI 模板单独添加一套运行时。若不能满足，先标明缺口与验收案例再扩展，不把 README 中的名词当成现成能力。

无互动是合法场景，不标记“玩法未完成”。普通场景需要明确片尾默认去向或有效的暂停等待出口；结局进入结束与重开。首版不承诺复杂并发互动：作者不得配置含糊的重叠可操作窗口，编辑器需提示调整；同一选择组中的多个选项属于一个互动窗口。

### 4.2 AI 的 P0 边界

- 支持图片/视频输出类型；图片支持文字生图与参考图生图，视频沿用现有模式。作者描述画面、选择参考素材及供应商实际支持的参数。
- 所选模型的合法默认参数可带入；参考素材由作者显式选择，提交前可见、可修改，不自动读取故事、当前选中对象或整份设定。
- 视频能力复用已签收 M2 及 W01–W06；图片与通用模型、来源、费用和多参考图按 06–09 及 02 的 CN/MR 增量执行，不把多角色一致性设为保证。
- 图片/视频生成均在独立工坊进行。场景、素材或设定里的生成入口如保留，只打开当前项目的工坊会话；未发送输入不跨离页或刷新恢复。
- 发送消息只整理可确认请求，不提交图片/视频任务。请求卡展示输出类型、有效描述、参数、参考输入、所属项目及适用的消耗预估；确认后创建任务。个人模型不展示费用，内置模型预估不扣减余额，详见 09。
- 允许针对上一图片/视频请求补充描述或修改参数，必须展示新的有效请求；不据此开放修改故事或玩法的命令。确定性整理即可，不强制为消息输入引入通用语言模型。
- 工坊消息、请求卡和任务按项目持久化；未发送输入仅存在于当前工坊组件内，图片/视频类型切换在当前页面中保留各自设置。消息不是项目命令，对话和任务不会随时间线撤销而删除。项目隔离、不可变输入快照和任务恢复必须有效。
- 生成内容可自动作为未采用素材进入项目库；只有明确“插入/替换”才改变作品时间线。
- 生成图片可明确“存为设定”；设定页“生成设定”仅直接进入普通工坊，不携带或保存设定表单，不自动提交或保存。选择某设定不隐式选择全部文件或其他设定；仅确认卡列出的文件/文本可外发。

## 5. 配套功能的收缩

- 项目名、画幅、语言等保留最小设置。
- 独立“设定”页管理项目媒体资料，公共字段＋分类扩展；多文件与校验规则见 [06](06-reference-library-and-image-generation.md)。旧文字及 other 资料保留并可补齐；不是角色知识图谱、声音生成库或锁定审批体系。
- 生成队列并入 AI 素材工坊，不再维护独立队列页与另一套任务历史。
- 原文是画布/场景参考资料，可编辑，不是生成或上传的强制前置审批。
- 新内置任务仅展示消耗预估，个人任务免计价；不检查、冻结或扣减旧项目额度，不做充值、订阅、交易和创作者分成。历史任务保留原费用快照与处理规则，见 09。

## 6. 本轮不做

- AI 编剧、AI 规划分支、AI 决定结局；作品叙事始终由作者负责。
- 自动目标识别、移动热点跟踪、换片自动重对齐、自动评分玩法是否好玩。
- 物品栏、线索收集系统、通用变量/条件编辑器、任意小游戏代码执行。
- 玩家的自由输入驱动实时剧情或视频生成。
- AI 音频/配音/音色克隆；音色仅上传或选择音频参考。AI 图片生成已按 1.2 明确纳入，不再属于排除项。
- 自动创建设定、关联推理/自动带入关联文件、跨项目设定库、自定义字段设计器。
- 多人协作、团队权限体系、内容广场、社交、市场、应用商店发布。
- Electron 客户端交付、本地模型部署、新字幕/转场/特效内核、跨设备玩家存档。

## 7. 本版取消的旧约束

不再把 15–30 分钟作品、商业画质持平、指定模型及其专有模式、玩法 AI 编译成功率设为本轮既定验收条件。保留成品质量关注，但采用对照测试和短作品闭环，避免用内容制作成本掩盖工具问题。

## 8. 模型配置的产品边界

模型配置有效权限以 [07](07-generic-model-configuration.md)、[08](08-model-source-modes.md) 为准，覆盖早期管理员专属约定。`MODEL_CONFIGURATION_ENABLED=false` 时只使用内置目录，隐藏并阻止配置入口/API；为 true 时登录用户只能管理自己的供应商、Key 和模型，工坊不回退内置目录。

可保存多个个人配置；名称、协议和 Model 的填写不证明支持相应输出。没有可用配置时，只阻止对应类型生成，不阻止上传与手工编辑，也不得静默切换来源或供应商。新内置任务按 09 预估，个人任务无价格也可用；真实模型测试仍需当次授权。

设为默认、启用、保存与实际可用是不同状态。个人默认按用户及图片/视频输出类型唯一；停用默认时取消对应默认，不自动选择替代。模型/凭据配置不属于项目导出、作品发布或项目撤销范围；历史连接与任务快照保持原版本。
