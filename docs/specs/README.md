## 本期交付范围

1. **AI 工坊是唯一 AI 创作界面。** 支持图片/视频生成、显式选参考媒体、请求确认、任务/结果、手动采用和图片存为设定。其他页面的生成快捷入口仅进入普通工坊，不传场景/片段或建立特殊返回流程。
2. **工坊与编辑器分别保持可用。** 工坊输入只在当前页面组件内保留，发送与确认继续保证幂等；编辑器保留对象属性、选择和播放位置。只维护本期实际使用的组件与状态，不留无调用代码。
3. **生成与采用分开。** 项目/账号隔离、请求输入与模型/文件快照、持久任务恢复和去重必须有效。新生成只入当前项目素材库，采用时才手选场景/片段并校验身份、revision、内容指纹及幂等。
4. **历史数据保持兼容。** 旧任务、消息、素材、版本及 scope/contextSnapshot 不通过破坏性迁移删除；旧编辑目标不注入新请求。历史开发证据保存在报告目录，不扩大本期要求。
5. **M4 完善基本可用性与发布。** T46–T48 的历史签收保留；其中普通工坊持久草稿及双标签草稿冲突要求已由 2026-10-05 简化决定撤销。阶段路线为 M2 → S1/已批准独立增量 → M4 → M5/M6。

当前有 73 项本期 T 任务、50 项有效 AC；T67/T68 与 AC-45 另保留原撤销记录。编号沿用既有身份，空号不复用、不顺延其他条目。计数不是产品完成率；实际状态见 todo。

## 继续有效的产品要求

- 产品名称 **Infinite Interaction**，保留 OpenFMV 来源说明与原时间线/播放器能力；主工作区为故事画布、场景剪辑器、AI 素材工坊。
- 页面无全局顶部栏。左侧导航支持展开/收起及短标签；画布单击主体进入场景，标题拖动、菜单编辑、出口连线。对象属性属于剪辑器，不由 AI 显隐。
- 无 AI 也能完成上传、剪辑、连线、手工互动、试玩和发布。不引入 AI 编剧、脚本拆解、玩法代理、声音生成/克隆或新剪辑内核。
- 四类设定统一名称、简介、至少一个主体文件；人物/场景/道具用图片，音色用音频，保留分类扩展及旧文字资料。上传/素材可建设定，生成图片明确保存；生成不自动建设定或修改作品。
- 设定关系需求于 2026-09-29 撤销，T67/T68/AC-45 保留历史 ID。设定表单无持久草稿，“生成设定”直接进普通工坊。生成时仅冻结作者显式选择的文件和必要文本，不展开关联或全部资料。
- 浏览器 Web SaaS、单人项目、PostgreSQL、私有对象存储、持久任务与不可变发布保持。内置/个人模型按 08，费用按 09；不增加支付、多人协作、供应商市场或本地模型部署。

## 2026-10-05 持久草稿简化

工坊未发送输入改为组件内存状态：当前工坊内切换生成/历史会保留输入，图片与视频共享提示词并分别保留模型、参数和素材；离开工坊、切换项目、刷新或关闭页面即丢弃。项目设置和场景资料也只保留当前已打开表单的未提交内容。PostgreSQL 不再保存工坊草稿，浏览器不再读取恢复副本；旧浏览器键只做一次尽力清理。消息、请求卡、任务、项目作品自动保存、撤销/重做及发布快照的持久化不受影响。详见[简化验收记录](../../tasks/reports/persistent-draft-removal-2026-10-05.md)。
